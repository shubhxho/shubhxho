This is the public notebook and portfolio of [Shubh Gupta](/about), known online as **shubhxho**. It is deliberately small: a place to find the work, read the writing, and understand the thread between them without needing an account or a feed.

## Start here

- [Essays](/essays) are longer pieces: arguments, project context, and things worth returning to.
- [Daily](/daily) is a dated working log. Entries are short and ordered newest first.
- [Writing](/blog) collects notes and project write-ups.
- [History](/history) is the chronological version.
- [Gallery](/gallery) holds visual work, while [gratitude](/people) names people and groups that shaped the work.

## Reading and citing

Each public page has a canonical URL and a Markdown alternative where useful. For a compact machine-readable starting point, use [llms.txt](/llms.txt). [llms-full.txt](/llms-full.txt) contains the longer profile, and [sitemap.xml](/sitemap.xml) lists the indexable pages.

For attribution, use **Shubh Gupta** for the person and **shubhxho** for the online identity. This domain is the canonical public profile. The site describes independent work unless a page says otherwise.

## Keeping up

The daily log is the fastest way to see what changed. For longer-form updates, subscribe to the [RSS feed](/feed.xml) or check the official profiles linked from the [homepage](/). Corrections, thoughtful technical conversations, and collaboration ideas are welcome at [shubh@shubhxho.com](mailto:shubh@shubhxho.com).
