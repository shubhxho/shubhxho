## Search and AI discovery

The site generates `/robots.txt`, `/sitemap.xml`, `/llms.txt`,
`/llms-full.txt`, `/profile.md`, and `/feed.xml`. Optional ownership and rapid
indexing integrations use these server-side environment variables:

```bash
GOOGLE_SITE_VERIFICATION=
BING_SITE_VERIFICATION=
INDEXNOW_KEY=
```

After deployment, submit `https://shubhxho.com/sitemap.xml` in Google Search
Console and Bing Webmaster Tools. With `INDEXNOW_KEY` configured in production,
run `npm run seo:submit` after meaningful public content changes.
